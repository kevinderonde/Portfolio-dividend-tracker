## ✨ What does this integration do?

Connect [Portfolio Dividend Tracker](https://portfoliodividendtracker.com/) to Home Assistant and monitor your portfolio through **31 summary sensors**. Financial totals update every **15 minutes**. Detailed records can be requested on demand instead of filling your Home Assistant Recorder database with individual transactions.

| 📊 Portfolio | 💰 Dividends | 📉 Performance | 🧾 Costs |
|:--|:--|:--|:--|
| Current portfolio value | Received dividends | Realised gains | Transaction costs |
| Cash balance | Gross dividends | Unrealised gains | Broker fees |
| Purchases and sales | Dividend taxes | Currency results | Conversion costs |

### Key features

- **31 portfolio summary sensors** for financial insights.
- **15-minute automatic updates** for the portfolio summary.
- **Read-only API authentication** using your personal PDT token.
- **On-demand data requests** for supported resources such as transactions and dividends.
- **Home Assistant dashboard-ready**: use the sensors in Entities, Tile, Statistics and other cards.
- **No automatic import of entire transaction histories into Recorder**.

### Install using Home Assistant Marketplace

1. Open **Home Assistant → Settings → Marketplace**.
2. Select **Add from link**.
3. Paste this repository URL:

   ```text
   https://github.com/kevinderonde/Portfolio-dividend-tracker
   ```

4. Add it as an **Integration** and follow the installation instructions.
5. Restart Home Assistant if prompted.
6. Go to **Settings → Devices & services → Add integration**.
7. Search for **Portfolio Dividend Tracker** and enter your **PDT read-only API token**.

### Manual installation

Copy `custom_components/portfolio_dividend_tracker/` into `/config/custom_components/`, restart Home Assistant and add the integration under **Settings → Devices & services**.

> [!CAUTION]
> Never publish your PDT API token in GitHub issues, screenshots or configuration examples. If it has been exposed, revoke it and create a new token.

The current release defines **31 unique summary sensors**. The names below match the integration's Dutch sensor labels. Actual entity IDs are generated by Home Assistant and may differ. Currency amounts use the currency supplied by PDT.

### 💼 Portfolio & performance — 11 sensors

| Sensor | Description |
|---|---|
| **Portefeuillewaarde** | Current total portfolio value. |
| **Cash** | Cash balance reported by PDT. |
| **Totaal resultaat** | Total portfolio result reported by PDT. |
| **Resultaat beleggingen** | Result attributable to investments. |
| **Ongerealiseerd resultaat** | Unrealised gains or losses. |
| **Ongerealiseerd resultaat beleggingen** | Unrealised investment result. |
| **Gerealiseerd resultaat** | Realised gains or losses. |
| **Gerealiseerd resultaat beleggingen** | Realised investment result. |
| **Valutaresultaat** | Total exchange-rate result. |
| **Ongerealiseerd valutaresultaat** | Unrealised exchange-rate result. |
| **Gerealiseerd valutaresultaat** | Realised exchange-rate result. |

### 📈 Purchases, sales & quantities — 7 sensors

| Sensor | Description |
|---|---|

| **Totale aankoopprijs** | Total purchase price reported by PDT. |

## 🔎 On-demand API data

The integration includes the Home Assistant action **`portfolio_dividend_tracker.get_data`**. It requests detailed information only when needed, helping avoid unnecessary Recorder/database growth.

Go to **Developer tools → Actions** and run:

```yaml
action: portfolio_dividend_tracker.get_data
data:
  resource: transactions
```

### Supported resource names

| Resource | Data category |
|---|---|
| `portfolio` | Portfolio summary |
| `transactions` | Transaction records |
| `dividends` | Dividend records |
| `bookings` | Account bookings |
| `expenses` | Expenses |
| `investment-strategies` | Investment strategies |
| `symbols` | Securities and symbol information |
| `prices` | Price data |
| `brokers` | Broker information |
| `calendar-events` | Calendar events |
| `exchange-rates` | Exchange-rate data |
| `changelog` | API changelog |

These are the resource names accepted by the current integration. Some PDT API requests may require additional parameters, appropriate account permissions or endpoint-specific handling. Availability of a resource does not mean it is automatically exposed as an entity.

## 🏠 Build your own dashboard

Combine the sensors with native Home Assistant cards or custom dashboards to show:

- Portfolio value, cash and total performance.
- Realised versus unrealised investment results.
- Dividend totals, tax and costs.
- Trading and broker fees.
- Currency-related gains and costs.

**Not included in this release:** individual stock/ETF sensor entities, a native dividend calendar entity, and a prebuilt dashboard. These may be added in future versions.

## 🛠️ Troubleshooting

| Issue | Check |
|---|---|
| Integration cannot connect | Check PDT API token, read permission and network access. |
| Sensor shows `Unknown` | PDT may not provide that field or value. |
| On-demand query fails | Check resource name, required API parameters and permissions. |
| Values are not updating | Check the integration status and Home Assistant logs. |
