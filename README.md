## ✨ What does this integration do?

Connect [Portfolio Dividend Tracker](https://portfoliodividendtracker.com/) to Home Assistant and monitor your portfolio through **31 summary sensors**. Financial totals update every **15 minutes**. Detailed records can be requested on demand instead of filling your Home Assistant Recorder database with individual transactions.

| 📊 Portfolio | 💰 Dividends | 📉 Performance | 🧾 Costs |
|:--|:--|:--|:--|
| Current portfolio value | Received dividends | Realised gains | Transaction costs |
| Cash balance | Gross dividends | Unrealised gains | Broker fees |
| Purchases and sales | Dividend taxes | Currency results | Conversion costs |

### Key features

- **31 portfolio summary sensors** for financial insights.
- **15-minute automatic updates** for the portfolio summary.
- **OAuth2 + PKCE sign-in**, with automatic access-token renewal; legacy read-only API tokens remain supported.
- **On-demand data requests** for supported resources such as transactions and dividends.
- **Home Assistant dashboard-ready**: use the sensors in Entities, Tile, Statistics and other cards.
- **No automatic import of entire transaction histories into Recorder**.

### Install using Home Assistant Marketplace

1. Open **Home Assistant → Settings → Marketplace**.
2. Select **Add from link**.
3. Paste this repository URL:

   ```text
   https://github.com/kevinderonde/Portfolio-dividend-tracker
   ```

4. Add it as an **Integration** and follow the installation instructions.
5. Restart Home Assistant if prompted.
6. Go to **Settings → Devices & services → Add integration**.
7. Search for **Portfolio Dividend Tracker** and select **Sign in with PDT (OAuth2)** or **Use existing API token**.

### Manual installation

Copy `custom_components/portfolio_dividend_tracker/` into `/config/custom_components/`, restart Home Assistant and add the integration under **Settings → Devices & services**.

> [!CAUTION]
> Never publish your PDT API token in GitHub issues, screenshots or configuration examples. If it has been exposed, revoke it and create a new token.

## 🔎 On-demand API data

The integration includes the Home Assistant action **`portfolio_dividend_tracker.get_data`**. It requests detailed information only when needed, helping avoid unnecessary Recorder/database growth.

Go to **Developer tools → Actions** and run:

```yaml
action: portfolio_dividend_tracker.get_data
data:
  resource: transactions
```

### Supported resource names

| Resource | Data category |
|---|---|
| `portfolio` | Portfolio summary |
| `transactions` | Transaction records |
| `dividends` | Dividend records |
| `bookings` | Account bookings |
| `expenses` | Expenses |
| `investment-strategies` | Investment strategies |
| `symbols` | Securities and symbol information |
| `prices` | Price data |
| `brokers` | Broker information |
| `calendar-events` | Calendar events |
| `exchange-rates` | Exchange-rate data |
| `changelog` | API changelog |

These are the resource names accepted by the current integration. Some PDT API requests may require additional parameters, appropriate account permissions or endpoint-specific handling. Availability of a resource does not mean it is automatically exposed as an entity.

## 📊 PDT Dashboard — Portfolio Performance

The Portfolio Dividend Tracker integration includes a **dedicated interactive dashboard** for Home Assistant, giving you a clear overview of your investments, dividends, costs and historical portfolio performance.

The dashboard is designed to work directly with the Portfolio Dividend Tracker integration and uses historical data from the PDT API.

### ✨ Dashboard features

- **Interactive performance chart** — Visualise your portfolio's historical performance.
- **5 selectable time periods** — Switch between 1 Month (1M), 3 Months (3M), Year to Date (YTD), 1 Year (1Y) and Maximum (MAX).
- **6 chart metrics** — Portfolio Value, Total Gains, Unrealised Gains, Realised Gains, Dividends Received and Transaction Costs.
- **Portfolio summary** — View current portfolio value, total gains and received dividends.
- **Adjustable column width** — Choose how many dashboard grid columns the card occupies using a slider.
- **Adjustable chart height** — Change the chart height using a slider.
- **Visual configuration editor** — Configure the card without manually editing YAML.
- **Responsive layout** — Adapts to different dashboard sizes and available screen space.
- **Manual refresh** — Update historical portfolio information whenever needed.
- **Home Assistant theme support** — Integrates with your existing dashboard appearance.

### 📈 Historical performance

The dashboard retrieves historical data using the integration's `portfolio_dividend_tracker.get_history` action.

Available time periods:

| Period | Description |
|---|---|
| **1M** | Last month |
| **3M** | Last three months |
| **YTD** | Year to date |
| **1Y** | Last year |
| **MAX** | Maximum available history |

Historical data is requested when needed, avoiding the creation of individual Home Assistant sensors for every historical data point.

### 🚀 Dashboard installation

The dashboard card is included with the Portfolio Dividend Tracker integration.

1. Install or update Portfolio Dividend Tracker through Home Assistant Marketplace.
2. Restart Home Assistant if required.
3. Open your Home Assistant dashboard.
4. Select **Edit dashboard → Add card**.
5. Search for **PDT Dashboard Card**.
6. Add the card and configure its settings.

The card requires an authenticated Portfolio Dividend Tracker integration (OAuth2 or personal API token).

### ⚙️ Dashboard configuration

Use the visual card editor to customise:

| Setting | Description |
|---|---|
| **Title** | Custom dashboard card title |
| **Column width** | Number of dashboard grid columns occupied by the card |
| **Chart height** | Height of the performance graph in pixels |

Example YAML configuration:

```yaml
type: custom:pdt-dashboard-card
```

Additional configuration options are available through the visual editor.

### 📊 Available chart metrics

| Metric | Description |
|---|---|
| Portfolio Value | Historical total portfolio value |
| Total Gains | Total realised and unrealised portfolio gains |
| Unrealised Gains | Gains or losses on positions not yet sold |
| Realised Gains | Gains or losses from completed sales |
| Dividends Received | Historical dividend income |
| Transaction Costs | Historical transaction-related costs |

> **Note:** Historical data availability depends on the information returned by the PDT API. Some periods or metrics may contain limited or unavailable data.

The PDT Dashboard Card works alongside your existing Home Assistant dashboards. Combine it with other cards, automations and financial sensors to create your own investment monitoring environment.

## 🔐 OAuth2 + PKCE (beta)

From v0.5.0, new installations can choose **Sign in with PDT (OAuth2)** or the legacy **API token** method. OAuth2 uses the registered public PDT application and Home Assistant's built-in PKCE flow, including refresh-token handling. Existing API-token installations continue to work without migration.

The public app may show **Not verified yet** until PDT approves it. For OAuth2, Home Assistant must support its OAuth callback and be accessible via the configured redirect mechanism. Do not share access or refresh tokens.

**Beta testing:** Verify that PDT accepts the authorization and refresh requests, and that `https://my.home-assistant.io/redirect/oauth` completes the login on your Home Assistant instance.
